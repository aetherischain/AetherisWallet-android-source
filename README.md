# AetherisWallet for Android

**AetherisWallet** is the official standalone Aetheris client for Android. It connects directly to the Aetheris network using [SPV](https://en.bitcoin.it/wiki/Thin_Client_Security#Header-Only_Clients) mode, and doesn't rely on servers that can be hacked or disabled.

---

## Easy and secure
AetherisWallet is the best way to get started with Aetheris. Our simple, streamlined design is easy for beginners, yet powerful enough for experienced users.

## Completely decentralized
Unlike other wallets, **AetherisWallet** is a standalone client. Even if the app is removed from the store, it will continue to function, allowing users to access their Aetheris at any time.

## Cutting-edge security
**AetherisWallet** utilizes AES hardware encryption, app sandboxing, and the latest Android security features to protect users from malware and physical theft. Private keys are stored safely on the user's phone, inaccessible to anyone else.

## Designed with new users in mind
Simplicity is **AetherisWallet**'s core principle. A simple 12-word recovery phrase is all that is needed to restore the user's wallet if they ever lose or replace their device.

## Features:
- "Simplified Payment Verification" (SPV) for fast mobile performance
- No server to get hacked or go down
- Single backup phrase that works forever
- Private keys never leave your device
- Import Aetheris from private keys
- Modern UI with Aetheris branding
